# Kod_asistan_basit_kayıt_akışı
# Uygulamanın adı : KOD-ASİSTAN BASİT KAYIT AKIŞI v0.1
## Uygulamanın amacı : kullanıcıdan alınan mantıksal verileri mantıksal bir şekilde işlemek ve sonucu akış şeması sembolleriyle tasarlamak.
